# deployment-test

Minimal React 18 + Vite + TypeScript app for testing [dFlow](https://dflow.sh) deployments.

## Local development

```bash
npm install
npm run dev
npm run build
npm run preview -- --host 0.0.0.0 --port 4173
```

## Deploy on dFlow

Connect this repo in dFlow and use `dflow.template.json` for install/build/start commands.
